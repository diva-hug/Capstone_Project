Capstone Project
================

A single public repository containing three modules:

1. data_pipeline       - scrape, clean, convert, store, query
2. analytics           - Titanic EDA and modeling pipeline
3. support_assistant   - Zepto RAG + FastAPI service

Each module lives in its own folder with its own README covering
install steps, run commands, and design decisions.

Repository: https://github.com/diva-hug/Capstone_Project
